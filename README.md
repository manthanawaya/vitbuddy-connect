# 📘 VITBuddy Connect

A **student portal for VIT Bhopal University** that simplifies access to essential services like **hostel management, health records, and attendance tracking**. Built with modern web technologies, this platform provides a secure and user-friendly interface for students.

---

## 🚀 Features
- **Authentication System**
  - Secure login with email and password
  - New user registration with sign-up option

- **Student Dashboard**
  - Centralized access to hostel, health, and attendance modules
  - Clean and responsive UI

- **Modules**
  - 🏠 **Hostel Management**: Room details, allocation, and requests
  - 🩺 **Health Records**: Medical history and appointments
  - 📊 **Attendance Tracking**: View attendance percentage and subject-wise records

---

## 🛠️ Tech Stack
- **Frontend**: React.js (Next.js for deployment on Vercel)
- **Backend**: Node.js / Express (API integration assumed)
- **Database**: MongoDB / Firebase (depending on implementation)
- **Deployment**: Vercel
